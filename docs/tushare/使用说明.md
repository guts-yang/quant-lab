## 最佳实践

Token 只放 `.env`，不要写进代码或 git。正式包的 `set_token` 会把 token 写到用户主目录的 `jsdata_tk.csv`。研究代码直接把环境变量传给 `get_api`：

```python
import os
import sxsc_tushare as ts

api = ts.get_api(token=os.environ["SXSC_TUSHARE_TOKEN"], env="prd")
df = api.daily(ts_code="000001.SZ", start_date="20261028", end_date="20261028")
```

日期用 `YYYYMMDD`，不要晚于最近一个已结束的交易日。全市场行情和财务按 `trade_date` 或 `period` 一次取完，不要对每只股票循环。财务先调 `*_vip`，返回无权限、接口不存在或未知数据源时，再按代码调普通接口。

重复使用的结果放进 `data/cache/`。这个目录已被 gitignore。空表要分开看：可能是非交易日，也可能是这次没有数据。行数正好卡在 3000 或 5000 时，按未取全处理。
