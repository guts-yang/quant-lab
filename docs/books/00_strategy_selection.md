# 00：策略选型

## 📖 【核心理论与量化直觉】

这里的排名是定性决策评分，不是历史收益榜，也不是胜率榜。先看综合分，再看策略逻辑和适用条件。基准场景是：A 股、机构可执行、日频到月频、流动性较好的股票池、适度多资产分散，并且不过度依赖杠杆。低换手基本面多因子和指数增强相对均衡；CTA 适合补充跨资产分散。市场阶段和资金规模会改变排序。

各维度按 1–5 分打分。实施难度反向计入易实施度，分越高表示越容易落地。五个符号依次是收益潜力 $R$、风险控制 $K$、稳健性 $B$、容量 $C$、易实施度 $E$：

$$
S=20\times(0.25R+0.25K+0.25B+0.15C+0.10E)
$$

风险控制分衡量策略风险是否较容易识别、约束或对冲，不等于策略本身没有风险。分数便于比较；整数上的小差距不代表真实表现有显著差别。加权结果的 `.5` 按四舍五入进位，例如 `77.5` 记为 `78`。

| 排名 | 策略类型 | 评分向量 | 综合分 |
|---:|---|---|---:|
| 1 | 低换手基本面多因子 | 3.5 / 4 / 4 / 4 / 4 | 78 |
| 2 | 指数增强 | 4 / 3.5 / 3.5 / 4.5 / 4 | 77 |
| 3 | 跨资产 CTA 趋势 | 4 / 4 / 3.5 / 4 / 2.5 | 75 |
| 4 | 股票市场中性 | 3.5 / 4 / 3.5 / 3 / 2.5 | 69 |
| 5 | 事件驱动 | 3.5 / 3 / 3 / 3.5 / 3 | 64 |
| 6 | 统计套利 / 配对 | 3.5 / 3 / 3 / 2.5 / 2.5 | 60 |
| 7 | 机器学习 / 另类数据 | 4.5 / 2.5 / 2.5 / 3 / 1.5 | 60 |
| 8 | 期权波动率策略 | 4 / 2.5 / 2.5 / 3 / 2 | 58 |
| 9 | 高频 / 做市 | 4 / 3 / 2.5 / 2.5 / 1 | 57 |

向量顺序是收益潜力 / 风险控制 / 稳健性 / 容量 / 易实施度。

| 策略 | 核心思路与较适合的市场 | 主要优势 | 主要风险 |
|---|---|---|---|
| 低换手基本面多因子 | 综合估值、盈利质量、现金流、资产负债表等信号选股；适合 A 股中长期、重视交易成本的资金 | 换手较低、容量相对较好，信号容易解释；可分散单一风格风险 | 因子可能多年跑输；财报发布时间处理不当会产生前视偏差；价值、低波等风格会阶段性失效 |
| 指数增强 | 持有基准指数附近的组合，以选股和权重优化争取超额收益；适合明确需要跟踪沪深 300、中证 500 等基准的资金 | 收益目标和风险基准较清楚，容量通常较好 | 仍承担市场下跌的 Beta 风险；风格偏离、拥挤和容量扩张会侵蚀超额 |
| 跨资产 CTA 趋势 | 在商品、股指、债券等期货上顺势做多或做空；较适合趋势清晰、资产间分化加大的环境 | 可做多空、覆盖多类资产，有助于分散股票风险 | 震荡市容易被假突破反复止损；杠杆、保证金、展期和快速反转会放大损失 |
| 股票市场中性 | 股票多头选股，同时用股指期货等工具对冲市场方向 | 降低大盘方向暴露，收益来源更偏向选股超额 | 对冲基差、交易成本和选股 Alpha 都影响结果；极端行情下相关性和流动性风险会变化 |
| 事件驱动 | 围绕财报、指数调样、回购、并购等事件建立规则化交易 | 逻辑较明确，部分事件的交易窗口可以事先定义 | 事件样本有限、规则和市场预期会变；成交跳空、执行延迟会使回测效果难以兑现 |
| 统计套利 / 配对 | 利用相关资产价差偏离后的均值回归；配对交易是常见实现方式 | 对市场方向依赖较低，可形成相对价值交易 | 价差关系可能结构性破裂；短周期交易容易被成本、拥挤和流动性吃掉收益 |
| 机器学习 / 另类数据 | 用非线性模型从价量、基本面或另类数据提取预测信号 | 能捕捉交互关系，适合数据丰富、研发和验证能力强的团队 | 过拟合、数据漂移、数据授权合规和复现难度较高；复杂模型不自动意味着更强泛化 |
| 期权波动率策略 | 交易隐含波动率、实际波动率、期限结构或偏斜 | 可构造方向性较低的风险敞口，风险形状可设计 | 尾部损失可能非线性；需要期权定价、动态对冲和保证金管理能力，流动性也有限 |
| 高频 / 做市 | 依赖盘口、报价和快速执行赚取价差或短时定价偏差 | 在具备技术和交易基础设施时，信号响应与风险处理可以很快 | 对低延迟系统、费用和执行质量高度敏感；竞争、监管约束和逆向选择风险高，普通团队难以复制 |

动量与反转更像信号家族，不是互斥的产品类别。动量常用于选股或 CTA 趋势；均值回归常用于统计套利、配对和部分短周期选股。同一团队可能把它们与基本面因子组合使用。

排名会在这些情况下变化：

- A 股上涨且个股分化较广时，指数增强可能更靠前，但总回报里仍包含市场 Beta。
- 商品或多资产出现持续趋势时，CTA 的相对吸引力上升；持续震荡时，反复反转可能使它落后。
- 资金规模很大时，小容量、依赖短周期价差的统计套利与高频更容易受冲击成本限制；大盘股、宽基指数和跨资产策略的相对容量可能更有利。
- 只看低换手、易落地时，基本面多因子通常更适合优先评估。低换手不能保证因子有效，也不能保证回撤较小。
- 做组合而不是单策略时，多策略可能改善收益来源的分散度。它是组合构建方式，不能与单一策略作完全同口径比较。策略相关性在压力期上升时，分散效果也会下降。

2026 年关于 A 股量化的报告指出，风格切换、策略拥挤和规模扩张会影响超额表现；同期 CTA 研究也显示子策略表现会随趋势与波动环境而分化。上表是策略属性的框架性比较，不是对当前产品或未来收益的预测。[中证网转载广发证券分析，2026-10-21](https://www.cs.com.cn/ssgs/07/2026/10/21/detail_2026102110046094.html)；[新浪财经 CTA 策略综述，2026-10-16](https://finance.sina.com.cn/roll/2026-10-16/doc-inivksmp7773127.shtml)

学术脉络可参考 Fama 与 French 的五因子模型（[2015](https://doi.org/10.1016/j.jfineco.2014.10.010)），以及 Moskowitz、Ooi 与 Pedersen 的时间序列动量研究（[2012](https://doi.org/10.1016/j.jfineco.2011.11.003)）。这些研究有助于理解因子和趋势策略的逻辑，不能直接当作 A 股实盘收益保证。

### 本仓库的 4 万元约束

上面的表保持机构可执行基准，这里不另造一套分数榜。本仓库落地的是排名第 1 的低换手基本面多因子：持仓 5–8 只，初始资金 4 万元。4 万元改变的是可执行性，不是把机构基准表重排。

单笔最低佣金 5 元、买卖按 100 股整手，使高频、做市和短周期价差策略的成本占比过高。股指期货单手名义本金远高于 4 万元，因此股票市场中性和需要股指期货对冲的做法当前不能执行。期权波动率还缺少定价、动态对冲和交易权限。机器学习与另类数据缺少稳定的数据授权和样本外验证流程。

指数增强、CTA、事件驱动和统计套利保留为后续可研究的类别，不进入当前代码路径。指数均线降仓只是股票组合的风险开关，不是市场中性，也不是 CTA。

## ⚠️ 【实盘避坑指南】

- 综合分来自启发式权重。`78` 与 `77` 的差距来自四舍五入后的整数，不能解释成胜率或预期超额。
- 风险控制分高，只说明约束手段相对清楚。CTA 的风险控制分为 4，同时仍有杠杆、保证金和趋势反转风险。
- 机构容量优势不能搬到 4 万元账户。小账户的第一约束是佣金下限、整手和可交易工具，不是策略能容纳多少机构资金。
- 财报按公告日之后才可使用。基本面多因子若用报告期代替可得日，会把未来信息写进历史排名。
- 风格拥挤和多年失效是这类策略的常态风险。回测凑出目标年化，不能反过来修改上表的定性分数。

## 💻 【仓库代码实战导引】

当前代码路径对应低换手基本面多因子：

- [core/cleaner.py](../../core/cleaner.py)：`UniverseCleaner.filter` 先做硬性排雷。

- [strategy/risk_control.py](../../strategy/risk_control.py)：`month_end_book`、`stop_price`、`index_exposure` 控制缓冲换仓、止损和指数仓位。

仓库没有指数增强基准跟踪、CTA、市场中性对冲、事件驱动、配对交易、机器学习训练、期权定价或高频做市模块。阅读代码时按上面四个入口核对，不要把指数仓位开关当成另一类策略。

离线确认选股边界仍在：


## 📊 【实验复现与指标预期】

本章没有单独的选股命令。运行上面的测试时，预期是合成数据全部通过，并且不访问网络。测试确认的是规则本身：综合分排序稳定、Top-N 只接受 5–8、止损和佣金下限按既定公式生效。

实盘或历史回测即使给出年化、回撤和卡玛，也只描述该段样本。它们不能改写本章的定性排名，也不能当成收益承诺。4 万元账户应先看交易次数、单笔佣金占比和最大回撤，再讨论收益潜力。
