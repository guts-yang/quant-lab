# 因子研究方法与实操手册

> **用途**：把一个市场观察或数据想法，转化为可复现、可证伪、经样本外检验的因子研究。
>
> **使用原则**：先定义目标和假设，再看数据；先检验预测力，再检验组合可交易性。回测结果是研究证据，不是未来收益保证，也不构成投资建议。

## 1. 先区分：风险因子、Alpha 信号与 Alpha

- **风险因子**描述资产或组合对共同风险来源的暴露，可用于解释收益为何共同变化、管理风险暴露。
- **Alpha 信号/因子**是用于预测未来收益或相对表现的可计算特征。
- **Alpha**是在指定基准、风险模型、样本区间和成本口径下，风险解释后仍观察到的超额部分。它不是脱离这些条件的固定属性。

同一个变量可能既是风险暴露，也被当作预测信号研究。只有在控制既定风险暴露、计入交易约束和成本后仍有样本外增量，才有理由称其具备可用的 Alpha 价值。

## 2. 研究开始前：写清楚研究任务卡

开始写公式或跑回测前，先填写下表。任何空项都可能改变结论；无法确定时先记为“待定”，不要默默采用方便的设定。

| 项目 | 需要填写的内容 |
|---|---|
| 研究问题 | 想解释或预测什么现象？为什么值得研究？ |
| 市场与股票池 | 市场、证券类型、纳入/排除规则、历史成分股处理方式 |
| 投资目标 | 相对哪个基准？做多、做多空，还是只做排序研究？ |
| 预测目标 | 个股未来收益、基准超额收益，或风险调整收益？明确收益口径 |
| 预测/持有周期 | 信号形成时点、持有期、调仓规则与交易延迟 |
| 组合约束 | 行业/市值/个股权重、流动性、做空、换手等限制 |
| 成本口径 | 佣金、税费、滑点、冲击成本；无法估计的项标明缺口 |
| 数据可用性 | 数据字段、供应方、历史覆盖、发布时间、修订机制、缺失情况 |
| 预先约定的判定 | 主指标、风险限额、稳健性检查、通过/失败/不确定规则 |

### 可直接套用的研究假设句式

> 在【市场/股票池】中，基于【当时可获得的数据】构造的【信号】，由于【经济机制或行为机制】，预计能在【预测周期】对【目标收益】提供方向为【正/负】的增量预测力；若这一机制不成立，或收益在控制【相关风险暴露】并计入【成本与约束】后消失，则拒绝该假设。

研究假设必须可被数据否证。只说“这个指标和收益相关”还不够：要说明数据在何时可得、预测什么、预计方向和期限，以及什么证据会让你放弃它。

## 3. 从市场假设到候选因子

### 3.1 先提出机制，再选择字段

常见假设来源包括：

- **信息扩散或反应不足**：新信息进入价格可能有时滞。
- **行为偏差或交易约束**：投资者行为、卖空限制或流动性限制可能形成可观察的价格模式。
- **基本面与预期变化**：经营质量、盈利变化或预期修正可能与未来相对表现相关。
- **风险补偿**：某种暴露可能对应额外风险补偿；此时应首先把它当作风险解释问题，而不是直接称为 Alpha。

这些是研究线索，不是有效性结论。候选因子必须与目标市场、投资周期及数据可用性匹配。

### 3.2 候选因子规格卡

每个候选因子都写一张规格卡，避免边测边改定义：

1. 因子 ID 与版本号。
2. 经济假设及预期方向。
3. 原始字段、计算公式、单位和时间戳规则。
4. 预测目标、收益区间、信号形成时点、执行时点。
5. 缺失值、异常值、标准化及中性化规则。
6. 股票池、筛选条件、再平衡和持仓规则。
7. 成本假设、风险约束和主要评价指标。
8. 开发集、验证集与锁定样本外的划分方式。
9. 已尝试过的定义、参数与失败结果。

### 3.3 公式写法示例（仅示范，不代表有效）

若研究价格趋势，可以定义某证券在时点 \(t\) 的历史收益信号：

\[
M_{i,t}=\frac{P_{i,t-k}}{P_{i,t-L}}-1,\quad L>k>0
\]

其中 \(P_{i,t-L}\) 与 \(P_{i,t-k}\) 必须对应研究者预先规定的历史价格时点；是否跳过最近一段、是否使用复权价格、如何处理停牌和不可交易价格，都应在规格卡中事先固定。该公式只是一个候选定义，不代表在任何股票池或时期中有效。

## 4. 数据治理：先保证“当时可知”，再计算因子

### 4.1 建立数据字典

至少记录：字段含义、来源、单位、覆盖范围、更新时间、历史修订规则、空值含义、复权方式、证券代码映射和授权/使用限制。版本更新后保留旧版本信息，保证研究可复现。

### 4.2 执行点时（Point-in-Time）检查

每条数据必须能回答：**市场参与者在信号形成和下单时是否已经知道它？**

- 财务字段用实际披露时间，不用财报期末日期代替公开时间。
- 分析师预期、成分股、行业分类等使用历史当时版本；不得用今天的覆盖关系回填过去。
- 信号只能读取决策时点之前的数据；如使用收盘价计算，不能假设同一收盘价已经成交。
- 修订数据要保留当时版本，避免未来修订泄露。

### 4.3 检查股票池与交易可行性

历史股票池应尽可能纳入退市、暂停上市和后来被剔除的证券，避免幸存者偏差。按市场规则处理停牌、涨跌停、上市初期、退市整理、公司行动和不可成交情况。若研究 A 股，还应明确 ST、停牌、涨跌停、上市时间不足、复权、退市和可卖空限制等规则；具体筛选应与研究目标一致。

### 4.4 做数据质量报告

报告字段覆盖率、日期范围、证券覆盖、重复记录、极值、缺失模式、异常跳变、时间戳错位和价格/收益一致性。修复规则应记录，不要通过删掉“表现不好”的样本来清理数据。

## 5. 构造因子与预测目标

### 5.1 对齐信号与未来收益

先定义信号时点 \(t\)，再定义未来收益标签，例如：

\[
y_{i,t}^{(h)}=\frac{P_{i,t+h}}{P_{i,t+\delta}}-1
\]

其中 \(\delta\) 表示从信号可得时点到可执行价格之间的延迟；\(h\) 是预先选定的预测持有期。价格、复权、执行时点、停牌与复权事件的处理口径必须保持一致。若标签期间互相重叠，后续验证需处理样本依赖和信息泄漏。

### 5.2 变换应有理由且在各时间折内拟合

常见处理包括截面排序、标准化、去极值、行业或规模中性化、缺失值处理和方向统一。处理方法会改变因子含义：

- 截面标准化便于比较，但要避免全样本统计量泄露到过去。
- 去极值可降低录入错误或异常点影响，但边界规则应事先固定。
- 中性化可降低已知风险暴露，但可能同时移除真实研究信号；要报告中性化前后差异。
- 缺失值填充必须区分“真实为零”“尚未披露”“数据缺失”，不可一概填零。

任何估计参数（例如标准化均值和方差、缺失值填充值、筛选阈值）都只能在训练窗口估计，再应用到对应验证/测试窗口。

## 6. 验证：从预测力到可交易组合

### 6.1 第一层：因子预测诊断

建议至少检查：

- **IC / Rank IC**：每个形成时点，计算因子值与对应未来收益的横截面相关或秩相关，再观察其时间序列均值、波动和稳定性。
- **分组单调性**：按因子排序分组，检查未来收益是否呈现符合假设的梯度；不能只看最高组。
- **方向与期限**：检查信号方向是否符合预先假设，预测力是否只集中在特定持有期。
- **稳定性**：按市场阶段、行业、规模、流动性等切片检查，留意效果是否被少数股票、少数月份或单一行业驱动。

IC 的统计显著性不等于策略可交易，更不等于独立 Alpha。报告使用的相关系数、横截面范围、时间聚合方法、缺失值规则和标准误处理方式。

### 6.2 第二层：组合回测

把信号转换为与目标一致的组合规则，并明确：排序/选股方式、权重、再平衡、持有期、行业和个股限制、交易延迟、无法成交处理、基准与现金收益口径。避免在看到结果后反复改变规则。

同时展示：

- 毛收益与成本后收益；
- 相对基准收益和风险调整表现；
- 波动、最大回撤、尾部损失或下行风险；
- 换手率、交易成本、容量/冲击成本敏感性；
- 市场、行业、规模、价值、动量等已知风险暴露；
- 多空组合的借券可得性、费率和回补约束（如适用）。

单一绩效指标不能替代完整判断。成本估计不确定时，做多档成本压力测试，并说明哪些成本尚未纳入。

### 6.3 第三层：样本外验证

采用按时间向前的验证，不要随机打乱时间序列：

1. 用较早时期做开发和训练。
2. 用后续时期做验证，筛选研究方案，但不把它当最终结果。
3. 冻结公式、参数、股票池和评价规则。
4. 只在锁定样本外运行一次最终评估；结果出来后如再调参，该区间就不再是未触碰样本外。
5. 使用滚动或扩展窗口做 walk-forward 检验；对重叠收益标签或持有期，按研究设计采用 purge/embargo 等隔离办法。

若样本外失败，应保留失败结果并解释可能原因，不能把它改称为“调参阶段”后继续使用同一段数据验证。

### 6.4 第四层：稳健性与增量价值

按预先列出的检查进行：不同时段、合理的持有周期、样本范围、成本假设、参数附近、行业/规模中性化前后、子行业与流动性分层、替代基准、与已有因子联合后的增量贡献。参数邻近区域结果若骤然崩溃，或收益完全由某个已知风险暴露解释，应降低结论等级。

## 7. 过拟合与选择偏差防线

1. **限制自由度**：先用少量有机制的候选；减少无依据的参数网格和反复改公式。
2. **保留试验台账**：记录每个候选、参数、失败结果、查看过的区间和最终筛选理由；不能只保存胜出的回测。
3. **锁定最终样本外**：不要在最终样本上反复观察、选择、再汇报。每次根据结果改动后，原测试集应视为已使用。
4. **处理多重检验**：尝试越多、筛选越激进，偶然胜出的概率越高。报告总试验数、筛选流程，并在试验数量和收益序列满足方法前提时考虑 DSR、PBO 等选择偏差审查；不得只报未经校正的最佳 t 值或 Sharpe。
5. **避免泄漏**：检查点时数据、未来函数、全样本标准化、成分股回填、标签重叠、信号与成交时间错位。
6. **用保守执行假设**：包含交易延迟、停牌/涨跌停和可成交限制，做成本与冲击敏感性分析。
7. **检查简约性与机制**：优先选择解释清晰、参数不敏感、跨时期相对稳定的规则。若移除某个复杂环节后结果消失，需确认它是否有独立经济理由，而非偶然拟合。
8. **诚实报告不确定性**：将“支持”“不支持”“证据不足”区分开；样本短、覆盖窄或数据质量差时，不以单个显著结果作强结论。

## 8. 研究决策门：通过、拒绝或继续观察

开始前先写下判定规则。结论不应只依据一次回测的最高收益。

| 结论 | 判定原则 |
|---|---|
| 继续进入更严格验证 | 假设清晰；数据时点可信；样本外存在增量；计入成本及约束后仍符合事前目标；已知风险暴露不能完全解释结果 |
| 拒绝当前定义 | 预测方向与假设相反；样本外不稳定；成本后优势消失；效果依赖未来信息、不可交易样本或极窄参数点 |
| 证据不足 | 样本量/时间跨度不足、数据缺失、成本或成交假设不可靠、多个检验结论冲突；先补证据，不宣称有效 |

“继续验证”不代表因子已被证明有效，也不代表可直接投入实盘。

### C. 最终研究报告最小目录

1. 研究问题与经济假设。
2. 因子公式、字段定义和时点规则。
3. 数据来源、覆盖范围、质量与偏差检查。
4. 股票池、目标收益、组合构造和交易成本。
5. 开发/验证/锁定样本外设计。
6. 因子预测诊断、组合表现、风险暴露与成本敏感性。
7. 稳健性、多重检验和失败试验记录。
8. 结论（支持/拒绝/证据不足）、限制与下一步。
9. 复现信息（数据版本、代码版本、参数、运行日志和文件哈希）。

## 10. 执行前后检查清单

### 执行前

- [ ] 假设、预测方向、期限和判定规则已写下。
- [ ] 信号时点与可交易时点明确，没有使用未来数据。
- [ ] 股票池及退市、停牌、成分股历史处理明确。
- [ ] 标签、复权、成本、基准及组合规则已固定。
- [ ] 开发、验证与最终样本外边界已冻结。
- [ ] 失败尝试和本次参数选择将被完整记录。

### 执行后

- [ ] 数据质量和点时检查通过或缺口已披露。
- [ ] 因子方向、IC/Rank IC、分组单调性与跨期稳定性已检查。
- [ ] 组合回测包含成本、风险暴露、换手和可交易性。
- [ ] 样本外没有被反复用于调参；试验次数已记录。
- [ ] 结论没有把风险补偿或特定暴露误称为独立 Alpha。
- [ ] 保存数据、代码、配置、运行记录和结果摘要，能够复现。

---

**边界说明**：本手册提供研究流程与检查框架，不包含真实行情、因子实测或收益承诺。具体门槛需根据市场、投资目标、样本量、交易成本和风险约束预先设定；历史回测不代表未来表现，也不构成投资建议。
