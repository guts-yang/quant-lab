# DCF 估值：宏观预设、财报模型和待审兜底

每股价值只有在主路径输入都齐了之后才计算。算不出来的公司级输入写成「无法计算」，可以附一条建议兜底；审核通过之前，兜底不进入估值数字，也不画出一条看起来完整的价值曲线。

下面分三层。数字如果没有新的、已被引用的权威口径，就沿用原来的宏观预设。

## 1. 宏观预设和估值结构

这些不是公司经营假设。现价、总市值、总股本和 β 来自行情，也不算预设。

| 输入 | 取值 | 来源 |
| --- | --- | --- |
| 无风险利率 \(r_f\) | 1.8% | 10 年期国债收益率，可用命令行覆盖 |
| 股权风险溢价 | 5.5% | Damodaran 中国口径 |
| 折现率夹取 | 6%–15% | \(r=r_f+\beta\times ERP\) 算出后再夹取。熊市、牛市的点差不再次夹回这个区间 |
| 永续增速 | 2.5% | 长期名义增长。必须低于该情景折现率 1 个百分点 |
| 第 \(N\) 年收入增速 | 2.5% | 预测期收入向这个长期增速收敛，同样必须低于该情景折现率 1 个百分点 |
| 预测年数 \(N\) | 7 | 估值结构 |
| β | 周收益对沪深 300 回归，窗口约 104 周，至少 52 周；Blume 调整 \(0.67\beta_{raw}+0.33\)，再夹到 0.5–2.5。不足 52 周时按 1 | 统计方法，不是经营假设 |

折现率：

\[
r=r_f+\beta\times ERP
\]

熊市在基准折现率上加 1.5 个百分点，牛市减 1 个百分点（且不低于 1%）。永续增速熊市再减 1 个百分点且不低于 0，牛市再加 0.5 个百分点。这两处点差是情景风险带，不是财报估计。

行业市销率、市盈率可以记在假设里作对照，不乘进股权价值。

## 2. 公司模型

只用这家公司已经公告的财务报表。行业中位数、10% 净利率、0.9 转换率、固定 10% 的稳定期 ROE、−20%–50% 的增速夹取、起始增速相对行业中位 1.5 倍的上限、熊/牛用 0.6 / 1.25 去改公司增速，都不再进入主估值。

分析师预期也不混进主路径。

### 收入增速

\[
g=\text{股权再投资率}\times ROE
\]

\[
\text{股权再投资率}=\frac{\text{净资本开支}+\text{运营资本变动}-\text{净债务发行}}{\text{归母净利}}
\]

归母净利非正时，再投资率没有定义。净资本开支不是「购建长期资产支付的现金」本身，还要有折旧或处置收回才能把毛额收成净额。运营资本变动和净债务发行同样必须来自现金流量表或资产负债表里已经有的字段。三项缺任何一项，再投资率无法计算，不用行业中位数，也不用 2.5% 顶上。

\[
ROE=\frac{\text{归母净利}}{\text{平均归属母公司股东权益}}
\]

平均权益是相邻两个年报期末、归属母公司股东权益的平均数。先读资产负债表。没有这张表，或没有归属母公司股东权益，ROE 标成无法计算，不用总资产减总负债去编造股东权益。

起始增速用同一年度的再投资率和 ROE 相乘。缺一则整项无法计算。这时建议兜底只能是该公司自己的收入复合增速；收入复合增速也没有时，建议值为空。

第 1 年到第 \(N\) 年，收入从 \(g\) 线性收到第 \(N\) 年的宏观收敛目标。

### 净利率

起始净利率是该公司 TTM 净利率：TTM 归母净利 / TTM 收入。TTM 缺任何一块就留空，不估计。

终值净利率是该公司近 5 个年报的合计净利率（利润之和 / 收入之和），并且不超过当前 TTM 净利率：

\[
m_N=\min(m_{\text{TTM}},\ m_{\text{5年合计}})
\]

不再向行业中位数靠拢，也不再用 10%。两个数缺一个，终值净利率无法计算；建议兜底是剩下的那一个本公司口径。

### 高成长期现金转换率

近 5 个归母净利为正的年度，取 \((\text{经营现金流}-\text{资本开支})/\text{归母净利}\) 的中位数。负值和大于 1 的值都保留，不再夹到 0.5–1.2，缺历史时也不再改用 0.9。

中位数为负时，财报数字照实记下，但不自动进入预测。外推负的转换率意味着预测期持续现金流出。若不愿这样外推，审核时可以把该字段批成 1.0 或 0；若接受外推，把批准值写成这个中位数。1.0 和 0 不是财报里的另一条口径，所以建议兜底留空。审核通过前，负值本身也不进入估值。

金融业（银行、保险、证券）仍用净利润模板：高成长期转换率取 1，这是模板，不是把该公司的现金转换率估成 1。稳定期 ROE 仍然要这家公司自己的历史。

### 稳定期

\[
ROE_{\text{stable}}=\text{该公司历史年度 ROE 的中位数}
\]

\[
\text{稳定期再投资率}=\frac{g_{\text{永续}}}{ROE_{\text{stable}}},\qquad c_{\text{stable}}=1-\text{稳定期再投资率}
\]

\(c_{\text{stable}}\) 再夹到 \([0,1]\)。\(ROE_{\text{stable}}\) 缺失或不是正数时，稳定期转换率无法计算，不再按 1 或按 10% 的 ROE 代入。建议值为空。可以在审核文件里批准一个正的 `stable_roe`，或直接批准 `stable_cash_conversion`；没有批准就不进入终值。

### 熊市和牛市

增速和净利率用该公司自己的历史年度收入增速、年度净利率。最近至多 5 个年度样本里，低位取最小、高位取最大。样本少于 3 个就标无法计算，不用 0.6 / 1.25，也不用行业分位。

折现率和永续增速仍用第 1 节的情景点差。

## 3. 无法计算与待审兜底

每条缺失或不能直接使用的主路径输入记成：

```json
{"field": "growth_start", "reason": "……", "proposed": 0.093, "status": "pending_review", "approved_value": null, "computed": null}
```

`status` 缺省是 `pending_review`。`proposed` 只能是该公司财报里的另一个真实口径；没有任何财报依据时为 `null`。`computed` 用来留下已经算出来、但还不能进入估值的数，例如负的转换率。

审核文件是 `valuation/fallback_approvals.json`。文件不存在，或没有该代码、该字段的条目时，兜底不生效。格式：

```json
{
  "approvals": [
    {"ts_code": "000034.SZ", "field": "growth_start", "value": 0.0932},
    {"ts_code": "000034.SZ", "field": "cash_conversion", "value": -0.477}
  ]
}
```

用户写入批准值之后，下一次估值才使用，并在报告里标「已审核兜底」。模型自己已经能用的正的转换率、再投资率和 ROE，不会被审核文件改掉。

任一主路径输入仍是待审时：

- 不把基准每股价值算成一个看起来完整的正式结果
- `report.md` 和 `assumptions.json` 写明无法计算的字段、原因、建议兜底和审核文件路径
- 情景表里的 `per_share` 为 `null`
- 命令行以非零退出码结束，并打印原因，不把它当成未捕获异常
- 网页计算过程显示无法计算和待审项，不把空价值画成估值曲线

旧的已发布假设里没有 `fallbacks` 字段时，页面仍按原来的表打开。

输入齐了之后，股权价值仍是显式期现金流现值加 Gordon 终值现值：

\[
V_0=\sum_{t=1}^{N}\frac{FCFE_t}{(1+r)^t}+\frac{TV_N}{(1+r)^N}
\]

\[
FCFE_t=Rev_t\times m_t\times c,\qquad TV_N=\frac{Rev_N(1+g)\,m_N\,c_{\text{stable}}}{r-g}
\]

终值净利率小于或等于 0 时，终值按 0 计。折现率必须大于永续增速。

权威参考：[DCF Valuation (ch12)](https://pages.stern.nyu.edu/~adamodar/pdfiles/acf3E/ch12.pdf)、[FCFE Models (ch14)](https://pages.stern.nyu.edu/~adamodar/pdfiles/valn2ed/ch14.pdf)、[Terminal Value (Myth 5.1)](https://pages.stern.nyu.edu/~adamodar/pdfiles/country/TerminalValue.pdf)。

## 4. 神州数码（000034.SZ，2026-11-16）

这次没有正式每股价值。以前那组「高成长期转换率夹到 50%、稳定期 ROE 取 10%、每股 4.86 元」不再使用。截面日之前已经公告的合并报表给出下面这些数。

| 项目 | 数值 | 怎么来的 |
| --- | --- | --- |
| TTM 收入 | 1781.1 亿 | 2026 年三季报累计 + 2025 年报 − 2025 年三季报累计 |
| TTM 归母净利 | 6.33 亿 | 同一套 TTM |
| TTM 净利率 | 0.355% | 6.33 / 1781.1 |
| 近 5 年合计净利率 | 0.586% | 高于当前，所以终值净利率不超过当前，仍是 0.355% |
| 5 年收入复合增速 | 9.32% | 本公司收入 CAGR。只作为起始增速的建议兜底 |
| 现金转换率中位数 | −47.7% | 近 5 个盈利年度 \((OCF-Capex)/归母净利\) 的中位数 |
| 最新年度 ROE | 5.16% | 归母净利 / 平均归属母公司股东权益 |
| 历史 ROE 中位数 | 8.46% | 稳定期用这个数 |
| 现价 / 总市值 / 总股本 | 21.55 元 / 219.1 亿 / 10.17 亿股 | 行情 |
| β / 折现率 | 1.97 / 12.64% | 周收益回归后 Blume 调整；\(1.8\%+1.97\times 5.5\%\) |

经营现金流的 TTM 拼不齐，所以 TTM 自由现金流留空。转换率用的是更早的完整年报。

两件事把正式估值挡住了：

1. **起始增速无法计算。** 现金流量表里只有经营现金流和购建长期资产支付的现金，没有折旧或处置收回，也没有运营资本变动和净债务发行。股权再投资率因此无法计算。ROE 虽然能从资产负债表算出 5.16%，但 \(g=\) 再投资率 \(\times\) ROE 缺了再投资率。不用行业中位数，也不退回 2.5%。建议兜底是本公司收入复合增速 9.32%，状态 `pending_review`，批准前不进入估值。
2. **高成长期现金转换率无法进入估值。** 财报中位数是 −47.7%，不再被改成 50%。建议兜底为空。若不愿把现金流出外推七年，可在审核文件里把 `cash_conversion` 批准为 1.0 或 0；若接受这个中位数，把批准值写成 −0.477。

历史 ROE 中位数 8.46% 是正的，所以稳定期转换率按公式可以写出 \(1-2.5\%/8.46\%\approx 70.4\%\)。它出现在情景表里，供核对，但没有和上面两个待审输入一起变成每股价值。基准、熊市、牛市的 `per_share` 都是 null。

熊市、牛市的公司增速和净利率来自神州数码自己的年度样本（5 个）：收入增速低位 −5.3%、高位 32.9%，年度净利率低位 0.19%、高位 0.98%。折现率 14.14% / 12.64% / 11.64% 和永续增速 1.5% / 2.5% / 3.0% 是情景设计。因为转换率仍待审，这三档都没有正式每股价值，也没有做反向 DCF 和敏感性。

命令 `python -m valuation.run --code 000034.SZ --asof 20261116` 会把上述原因写到 `data/research/valuation_000034_SZ/`，并以非零退出码结束。

## 5. 代码

| 文件 | 做什么 |
| --- | --- |
| `valuation/model.py` | 收入路径、折现、Gordon 终值。输入必须已经齐 |
| `valuation/assumptions.py` | 公司模型和三情景。待审输入不送进引擎 |
| `valuation/fallbacks.py` | 待审记录，以及审核文件的读取 |
| `valuation/fallback_approvals.json` | 用户写入的批准。仓库里默认没有这个文件 |
| `valuation/data.py` | 公告日对齐、TTM、ROE、再投资率字段是否够用 |
| `valuation/discount.py` | β 和股权成本 |
| `valuation/scenario.py` | 报告和表。缺关键输入时每股价值为 null |
| `valuation/run.py` | 命令行。无法计算时退出码非零 |
| `web/charts.py` | 有待审兜底时说明无法计算，不画价值曲线 |
